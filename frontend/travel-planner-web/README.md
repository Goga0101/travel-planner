# travel-planner-web

Angular 21 frontend of the Travel Planner MVP. See the root [README](../../README.md).

```bash
npm install
npm start                      # http://localhost:4200, proxies /api to http://localhost:5080
npx ng build                   # dist/travel-planner-web/browser
npx ng test --watch=false      # Vitest + jsdom
```
